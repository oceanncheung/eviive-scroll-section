Marked golden by Ocean on 2026-08-02, at commit `88596e4`.
This is the SHIPPED module (`dist/eviive-section.js`), byte-identical to what
GitHub Pages served when marked — not a standalone page like v1.2. It mounts
via `mount(host)` from EviiveSection.tsx on the Framer homepage.

## What this version is

- THE STOP MODEL: natural scroll ends above the section with a 15% peek band;
  a bobbing Phosphor ArrowDown (click = enter) hints onward; one flick performs
  a pre-set 1800ms entrance on cubic-bezier(0.25, 0.10, 0.10, 1) with the
  reveal playing during the rise; one more flick -> EVIIVE (golden scene tween,
  2600ms); exit gate only at EVIIVE.
- Play-once per page load: ANY release spends the visit (the known caveat:
  an accidental up-flick at scene 1 silently kills the choreography — the
  change tried immediately after this mark addresses exactly that).
- Gesture engine: 140ms quiet boundary, consumed tails owned, fresh-intent
  rising-delta re-arm, TOLERANCE 24.
- iOS: momentum settle-resolver, visualViewport re-measure, frame self-sizing.
- Stability: schedule-first armoured driver loop, tween-invariant healer
  ("[eviive] healed a dropped scene tween"), armoured glide.
